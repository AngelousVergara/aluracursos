# Proyecto Amigo Secreto

Este es un sencillo proyecto de una aplicación web para realizar el sorteo del "Amigo Secreto".

## Descripción

La aplicación permite a los usuarios agregar una lista de participantes y luego sortear de manera aleatoria un "amigo secreto" de esa lista. Es una herramienta simple y divertida para organizar intercambios de regalos.

## Funcionalidades

-   **Agregar participantes:** Los usuarios pueden escribir los nombres de los amigos que participarán en el sorteo y agregarlos a una lista.
-   **Sortear amigo secreto:** Con un solo clic, la aplicación selecciona un nombre al azar de la lista de participantes.
-   **Visualización de resultados:** El nombre del amigo secreto sorteado se muestra en la pantalla.
-   **Interfaz amigable:** Un diseño limpio e intuitivo para una fácil utilización.

## ¿Cómo usar?

1.  Abre el archivo `index.html` en tu navegador web.
2.  Escribe el nombre de un participante en el campo de texto.
3.  Haz clic en el botón "Añadir" para agregarlo a la lista.
4.  Repite el proceso hasta que todos los participantes estén en la lista.
5.  Haz clic en el botón "Sortear amigo" para revelar el amigo secreto.

## Tecnologías Utilizadas

-   HTML5
-   CSS3
-   JavaScript
